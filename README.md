# Team Almeida Fight

Site institucional da Team Almeida Fight, academia de artes marciais com modalidades de Boxe, Jiu-Jitsu, Muay Thai e MMA. O projeto apresenta a equipe, horários, modalidades, loja e formas de contato para agendamento de aula experimental.

**Site:** [almeida-fight.pages.dev](https://almeida-fight.pages.dev/)

## Tecnologias

- TypeScript e Preact
- Cloudflare Pages
- Tailwind CSS

## Desenvolvimento

```bash
npm install
npm run dev
```

## Deploy

Conecte este repositório ao Cloudflare Pages usando GitHub. Configure `main` como branch de produção, `npm run build` como comando de build e `dist` como diretório de saída. Commits nas outras branches recebem URLs de preview automáticas.
