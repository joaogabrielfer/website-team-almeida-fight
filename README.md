# Team Almeida Fight

Site institucional da Team Almeida Fight, academia de artes marciais com modalidades de Boxe, Jiu-Jitsu, Muay Thai e MMA. O projeto apresenta a equipe, horários, modalidades, loja e formas de contato para agendamento de aula experimental.

**Site:** [almeida-fight.lakebed.app](https://almeida-fight.lakebed.app)

## Tecnologias

- TypeScript e Preact
- Lakebed
- Tailwind CSS

## Desenvolvimento

```bash
npx lakebed dev
```

## Deploy

Todo push na branch `main` dispara o deploy na Lakebed pelo GitHub Actions. Para funcionar, o repositório precisa ter o segredo `LAKEBED_TOKEN` configurado.
